## О проекте

StackCard — проект конструктора портфолио для разработчиков. Его задача —
собрать навыки, опыт и выбранные проекты в общей базе, а затем подготовить
отдельные резюме и портфолио для работодателя, заказчика или коллеги.

GitHub хранит исходный код и историю работы. Для портфолио нужен рассказ
о результате: что делает проект, какую задачу решает, какие технологии
использует и где его можно посмотреть. StackCard объединяет эти сведения
с описаниями, изображениями и ссылками, выбранными самим автором.

Продукт рассчитан на работу с телефона и из браузера: общий аккаунт, одна
база и библиотека проектов, несколько независимых резюме и портфолио.
Каждый документ имеет собственные секции, выбранные проекты и публичную версию.

## Возможности

<div align="center">

| **Возможность** | **Для чего нужна** |
|:---|:---|
| Профиль разработчика | Представить себя, навыки, опыт, образование и профессиональные ссылки |
| Витрина проектов | Показать отобранные работы с описаниями, технологиями, изображениями и demo |
| Импорт из GitHub | Использовать публичные репозитории как основу, дополняя их собственным рассказом |
| Smart GitHub Sync | Получать предложения об обновлениях проектов и принимать их после просмотра |
| Резюме и портфолио | Создавать независимые документы из общей базы, выбирать проекты, порядок и видимость секций, проверять результат в preview |
| Публичные документы | Публиковать выбранное резюме или портфолио, обновлять и отзывать его, делиться постоянной ссылкой |
| Обращения и Inbox | Читать сообщения по опубликованным документам; контактная форма и push работают при подключённом сервере |

</div>

## Как работает StackCard

1. **Заполнить общую базу.** Добавить информацию о себе, навыках, опыте,
   образовании и контактах.
2. **Собрать проекты.** Создать карточки вручную или выбрать публичные
   репозитории GitHub. Дополнить их описаниями, изображениями и ссылками.
3. **Подготовить документ.** Создать резюме или портфолио, выбрать проекты
   и секции, настроить порядок и видимость и проверить preview.
4. **Опубликовать и поделиться.** Подтвердить публикацию и отправить ссылку
   на выбранный документ.

После публикации работа продолжается в черновике. Smart GitHub Sync предлагает
добавить новый репозиторий или обновить сведения о существующем проекте.
Автор просматривает изменения, принимает нужные и сам решает, когда обновить
публичную страницу. Изменение общей базы тоже не перезаписывает документы:
автор просматривает предложенные замены и применяет их выборочно.

## Мобильное приложение и сайт

<div align="center">

| **Формат** | **Сценарий использования** |
|:---|:---|
| Android и iOS | Редактирование с телефона, локальный черновик без сети, preview и отправка опубликованной ссылки |
| Web-редактор | Общая база, проекты и независимые документы из браузера, preview и публикация |
| Публичный сайт | Знакомство со StackCard, информация о мобильном приложении и просмотр опубликованных резюме и портфолио |

</div>

Изменения между редакторами передаются через синхронизацию. Мобильный
черновик рассчитан на редактирование без сети; web-редактор — на работу
с подключением к интернету. Посетителю портфолио нужен только браузер.
