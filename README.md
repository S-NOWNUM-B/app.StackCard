## О проекте

StackCard — проект конструктора портфолио для разработчиков. Его задача —
собрать навыки, опыт и выбранные проекты в одну публичную страницу, которую
можно отправить работодателю, заказчику или коллеге.

GitHub хранит исходный код и историю работы. Для портфолио нужен рассказ
о результате: что делает проект, какую задачу решает, какие технологии
использует и где его можно посмотреть. StackCard объединяет эти сведения
с описаниями, изображениями и ссылками, выбранными самим автором.

Продукт рассчитан на работу с телефона и из браузера: два редактора одного
портфолио, общий аккаунт и одна публичная версия.

## Возможности

<div align="center">

| **Возможность** | **Для чего нужна** |
|:---|:---|
| Профиль разработчика | Представить себя, навыки, опыт, образование и профессиональные ссылки |
| Витрина проектов | Показать отобранные работы с описаниями, технологиями, изображениями и demo |
| Импорт из GitHub | Использовать публичные репозитории как основу, дополняя их собственным рассказом |
| Smart GitHub Sync | Получать предложения об обновлениях проектов и принимать их после просмотра |
| Конструктор портфолио | Выбирать блоки, менять их порядок и видимость, проверять результат в preview |
| Публичная страница | Делиться одной ссылкой и получать обращения через контактную форму |
| Developer Card | Представлять себя компактной цифровой визиткой с QR-кодом на портфолио |

</div>

## Как работает StackCard

1. **Заполнить профиль.** Добавить информацию о себе, навыках и опыте.
2. **Собрать проекты.** Создать карточки вручную или выбрать публичные
   репозитории GitHub. Дополнить их описаниями, изображениями и ссылками.
3. **Подготовить портфолио.** Выбрать нужные блоки, расставить их в удобном
   порядке и посмотреть, как страницу увидит посетитель.
4. **Опубликовать и поделиться.** Подтвердить публикацию и отправить ссылку
   на портфолио или цифровую визитку.

После публикации работа продолжается в черновике. Smart GitHub Sync предлагает
добавить новый репозиторий или обновить сведения о существующем проекте.
Автор просматривает изменения, принимает нужные и сам решает, когда обновить
публичную страницу.

## Мобильное приложение и сайт

<div align="center">

| **Формат** | **Сценарий использования** |
|:---|:---|
| Android и iOS | Редактирование с телефона, работа с локальным черновиком без сети и обмен визиткой |
| Web-редактор | Работа с тем же профилем и проектами из браузера, preview и публикация |
| Публичный сайт | Знакомство со StackCard, информация о мобильном приложении и просмотр опубликованных портфолио |

</div>

Изменения между редакторами передаются через синхронизацию. Мобильный
черновик рассчитан на редактирование без сети; web-редактор — на работу
с подключением к интернету. Посетителю портфолио нужен только браузер.
