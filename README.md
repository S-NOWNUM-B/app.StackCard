## О проекте

StackCard — проект конструктора портфолио для разработчиков. Его задача —
собрать профиль, навыки, опыт и выбранные проекты в одном портфолио для работодателя, заказчика или коллеги.

GitHub хранит исходный код и историю работы. Для портфолио нужен рассказ
о результате: что делает проект, какую задачу решает, какие технологии
использует и где его можно посмотреть. StackCard объединяет эти сведения
с описаниями и ссылками, выбранными самим автором.

Продукт рассчитан на работу с телефона и из браузера: общий аккаунт, одна
основное портфолио и библиотека проектов. Сохранённую версию можно
скачать в PDF или явно опубликовать и отправить постоянную ссылку.

## Возможности

<div align="center">

| **Возможность** | **Для чего нужна** |
|:---|:---|
| Профиль разработчика | Представить себя, навыки, опыт, образование и профессиональные ссылки |
| Витрина проектов | Показать отобранные работы с иконками, описаниями и ссылками |
| Импорт из GitHub | Использовать публичные репозитории как основу, дополняя их собственным рассказом |
| Иконки проектов | Выбирать знакомую иконку из каталога для библиотеки и портфолио |
| Основное портфолио | Заполнять необязательные поля, выбирать проекты и порядок в одном редакторе |
| PDF | Скачать сохранённое портфолио с фото, кириллицей и активными ссылками |
| Публичные документы | Публиковать основное портфолио, обновлять и отзывать его, делиться постоянной ссылкой |
| Обращения и Inbox | Читать сообщения по опубликованным документам; контактная форма и push работают при подключённом сервере |

</div>

## Как работает StackCard

1. **Открыть Редактор.** Добавить информацию о себе, навыках, опыте,
   образовании и контактах; ненужные поля можно оставить пустыми.
2. **Собрать проекты.** Создать карточки вручную или выбрать публичные
   репозитории одного профиля GitHub. Дополнить их описаниями и ссылками.
3. **Сохранить портфолио.** Выбрать проекты из библиотеки, настроить порядок
   и нажать «Сохранить». Главная покажет готовую сохранённую версию.
4. **Опубликовать и поделиться.** Подтвердить публикацию и отправить ссылку
   на портфолио либо скачать PDF.

После публикации работа продолжается в редакторе. Автор сам решает, когда
обновить публичную страницу; Save и импорт GitHub не публикуют изменения.

## Мобильное приложение и сайт

<div align="center">

| **Формат** | **Сценарий использования** |
|:---|:---|
| Android и iOS | Редактирование с телефона, локальный черновик без сети, preview и отправка опубликованной ссылки |
| Web-редактор | Основное портфолио и библиотека проектов из браузера, PDF и публикация |
| Публичный сайт | Знакомство со StackCard, информация о мобильном приложении и просмотр опубликованного портфолио |

</div>

Изменения между редакторами передаются через синхронизацию. Мобильный
черновик рассчитан на редактирование без сети; web-редактор — на работу
с подключением к интернету. Посетителю портфолио нужен только браузер.
